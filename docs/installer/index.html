INSTALL FM-XY.

A streamlined firmware installer for M-VAVE FM1, based on Felucca’s established package, backup and update system. Installation is unavailable until all release gates pass.

01 / Backup

Keep your music safe.

Before installing, save your current projects, presets, user samples and settings. The release installer will require a verified backup step before any firmware write.

02 / Connect

Verify the device.

The approved installer will use Felucca’s Web MIDI transport in Chrome or Edge over a USB data cable. Device identity and firmware compatibility must be checked first.

03 / Validate

Check the package.

Only a published FM-XY .fwsc release with an independently checked SHA-256 checksum and retained licensing information will be accepted.

04 / Install & recover

Update safely.

Felucca’s tested updater handles the transfer. Recovery instructions and a verified restoration procedure must be available before flashing is enabled.

No device connection, package download or flash operation can start from this page.

Release requirements

  • Native FM-XY build succeeds and Felucca audio, UI, editor, storage and package regressions pass.
  • Full ROOT/TYPE chord performance is implemented and verified in the native C firmware.
  • CPU, RAM, latency and 8-voice behavior meet the baseline on real FM1 hardware.
  • Backup, interrupted USB update, return-to-stock and recovery have been tested.
  • Release package, SHA-256, third-party licenses and user instructions are published.
