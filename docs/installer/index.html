Before installation

  1. Reproduce an unmodified Felucca build using the JieLi toolchain and AC79 SDK.
  2. Port FM-XY graphics, harmonic suggestions, navigation and settings into Felucca C sources.
  3. Build the firmware-backed WebAssembly emulator from those same sources.
  4. Run host regression, UI overflow and audio/CPU budget tests, then FM1 endurance and latency tests.
  5. Verify backups, restoration and device recovery on real hardware.
  6. Publish an audited .fwsc release with SHA-256 checksums and unlock the installer.
