# FM-XY

**Middle Age Engineering** · [Play FM-XY](https://taorminator.github.io/FM-XY/try/) · [Source](https://github.com/Taorminator/FM-XY)

A minimal groovebox concept for M-VAVE FM1: chord suggestions, four tracks, 16-step loops, and filter automation.

The [browser demo](https://taorminator.github.io/FM-XY/try/) is playable. The native firmware is **in development and not installable**.

## Themes
OP-XY Mono · OP-1 Color · OP-XY Color. Hold HOME in the demo to switch.

## Firmware
Our first C changes extend [Felucca](https://github.com/hugelton/Felucca) without replacing its audio engine or update/recovery code. See [firmware/README.md](firmware/README.md). No verified FM1 package exists yet.
