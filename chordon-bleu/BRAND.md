# CHORDON BLEU identity

## Naming decision

Write the **official product name as CHORDON BLEU** (two words). Case is flexible in prose; logo normally uppercase. **CHORD—ON—BLEU** is a playful *visual treatment*, not another official name. Keep `chordon-bleu` lowercase and hyphenated for GitHub, Git tags, packages, URLs, and filesystem use.

- Product: **CHORDON BLEU**
- Studio: **Middle Age Engineering**
- Short maker signature: **MID Engineering**
- Strapline: **Cook up something beautiful.**
- Category: *A pocket-sized harmony kitchen.*

## Interface nouns / actions

- PLAY: transport
- FLIP: create a musically guided variation
- SAVE: explicitly persist favorite loop; clarity wins over culinary jokes
- SPICE: harmonic novelty control, MILD > MEDIUM > SPICY > EXTRA HOT
- ROOT / TYPE: editable or AUTO, independently, per chord
- REC: capture a tiny chord sequence
- UNDO: reversible accidents
- MELT and CRISPY: experimental momentary effects. Ensure their sound actually matches each label before shipping.
- The library of saved loops can be called **RECIPES**.

## Art direction

Color base: `#0D1020` midnight, `#4657FF` neon blue. Gradient through `#7164FF` purple, `#A66AE3` lavender, `#D66AA2` pink, `#FA8078` coral to `#FFAD53` orange.

Think: restrained Apple-level clarity + playful geometric instrument typography. Familiar icons paired with labels, finger-friendly targets, generous contrast. No essential meaning conveyed by color alone. First interactions must be intelligible without a manual.

Temperature is a visual characterization based on sound/harmonic tension; avoid promising an objective warm/cold music-theory metric.

## Release policy

Check for prior use/trademark conflicts before any commercial public launch. Preserve existing software credits/licenses. The product is independently made, not associated with Teenage Engineering.
